01 — About

A systems engineer who treats security as a feature, not an afterthought.

I'm Leonardo Forconi, a DevOps and Cyber Security engineer based in Florence, Italy. I work where availability, confidentiality and regulatory compliance collide — critical infrastructures, payment platforms, air-gapped environments — and I help engineering teams ship safely in those constrained spaces.

My background spans system administration, network engineering, software development (C# / .NET) and security operations. I have led PCI-DSS Level 1 certification, migrated legacy estates to Infrastructure as Code, designed CI/CD pipelines for distributed systems, and built applications that run in fully isolated environments with no administrative rights.

Today I focus on Kubernetes (K8s / K3s), eBPF-based observability and security (Cilium, Tetragon), and the boring, repeatable workflows (SOPs) that keep complex systems running predictably. I care about least privilege, auditability and making the secure path the easy path.

Outside of work, I tinker with Kubernetes deployments, contribute to open source, and keep a personal blog at leonardoforconi.com.
