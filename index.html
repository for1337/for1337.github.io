02 /observe/

A systems engineer who treats security as a feature, not an afterthought.

Florence-based engineer. Ten years building and operating large-scale critical IT — payment platforms, air-gapped systems, regulated environments. The thread across all of it: make the secure path the easy path.

Background spans system administration, network engineering, software (C# / .NET), and security operations. Led PCI-DSS Level 1 certification, migrated legacy estates to Infrastructure as Code, designed CI/CD for distributed systems, and shipped applications that run in fully isolated environments under least-privilege.

Today: Kubernetes (K8s, K3s), eBPF (Cilium, Tetragon), and the boring repeatable workflows (SOPs) that keep complex systems running predictably.

Personal log at leonardoforconi.com.

obs. The “air-gapped” constraint isn’t exotic — it’s the same problem every regulated environment has, just with extra steps.

obs. If the secure path is harder than the insecure path, the team will route around you.
